# EKMG LLC

Bilingual English and Spanish website for EKMG LLC.

Open index.html for English or index-es.html for Spanish. All pages and assets are static; no build step is required.

Pages: Home, About Us, and Info, with a language switch on every page.

Contact: info@ekmg-global.com

This repository contains a copy of the website. GitHub changes do not automatically deploy to the separately hosted ChatGPT Site.
